# Gemini CLI 使い方マニュアル

Gemini CLI をより効率的・強力に活用するために抑えておくべきコマンドや操作方法を、優先度（High / Middle / Low）に分類して網羅的にまとめました。

---

## 🔴 Priority: High (日常的によく使う基本操作とフラグ)

日々の開発作業で最も頻繁に使用するコマンドや、生産性に直結するオプションです。

### 基本の起動コマンド
- **`gemini`**
  通常の対話モード（インタラクティブモード）で起動します。プロンプトへの入力待ち状態になります。

- **`gemini -p "プロンプト"`** / **`gemini --prompt "プロンプト"`**
  非対話（ヘッドレス）モードで実行。指定したプロンプトの指示を一度だけ実行し、終了します。単発のタスクや、他のスクリプトからの呼び出しで活用します。

- **`gemini -i "プロンプト"`** / **`gemini --prompt-interactive "プロンプト"`**
  引数で渡したプロンプトを先に実行し、処理完了後そのまま対話モードに移行します。「とりあえずこのファイルを直して、詳細は後でやり取りする」といったケースで非常に便利です。

### セッション・履歴の管理
- **`gemini --list-sessions`**
  現在のプロジェクトで保存されている過去のセッション一覧を表示します。

- **`gemini -r <session_id>`** / **`gemini --resume <session_id>`**
  過去のセッションを再開します。`<session_id>` には `--list-sessions` で表示されるインデックス番号を指定します。
  直近のセッションを再開したい場合は **`gemini -r latest`** が便利です。

### 承認プロセスの自動化 (YOLOモード)
- **`gemini -y`** / **`gemini --yolo`**
  すべてのツール実行やファイル編集の確認（Yes/No）を自動で承認するモードです。一連の作業が長くなる際、エンターキーを何度も押す手間を省けます。

### vimを用いたオススメコマンド・操作方法
- **`:!gemini -p "プロンプト"`**
  Vimのノーマルモードから外部コマンドとしてGemini CLIを実行します。出力を一時的に確認したい場合に便利です。
- **`:r !gemini -p "プロンプト"`**
  Gemini CLIの実行結果（標準出力）を、Vimで編集中の現在のバッファ（カーソル位置）に直接挿入します。自動生成されたコードや文章をそのままファイルに取り込みたい場合に強力です。
- **`:%!gemini -p "以下のコードをリファクタリングして"`**
  ファイル全体（`%`）を標準入力としてGeminiに渡し、その実行結果でファイルの中身を上書き置換します。（ビジュアルモードで選択した範囲に対して `:'<,'>!gemini ...` を実行すれば、部分的な置換も可能です）
- **`:term gemini`**
  Vimのターミナル機能を利用して、画面分割しつつ片方でGeminiの対話モードを開きます。Geminiが説明したコードを選択して、そのまま隣の編集バッファ（自分のソースコード）へヤンク（コピー）＆ペーストできるため、ツールの切り替えによるストレスをなくせます。

## 🟡 Priority: Middle (機能拡張・開発効率化ツール)

開発環境に合わせたカスタマイズや、外部知識・ツールの統合を行うためのコマンド群です。

### スキルの管理 (Skills)
エージェントに対して特定のライブラリやフレームワークの知識（ドキュメント等）を読み込ませる機能です。
- **`gemini skills list`** : 利用可能なスキルの一覧を表示します。
- **`gemini skills install <url>`** : Gitリポジトリなどから新しいスキルを追加します。
- **`gemini skills enable <name>`** / **`disable <name>`** : プロジェクトごとに必要なスキルの有効化・無効化を切り替えます。

### MCP (Model Context Protocol) サーバーの管理
Gemini CLI が外部のツールやAPI、ローカルのシステムと連携できるようにするための拡張機能です。
- **`gemini mcp list`** : 設定済みのMCPサーバー一覧を表示。
- **`gemini mcp add <name> <command>`** : 新規のMCPサーバーを登録します。
- **`gemini mcp enable <name>`** / **`disable <name>`** : サーバーを有効化・無効化します。

### 安全なワークスペースの作成
- **`gemini -w`** / **`gemini --worktree`**
  新しい Git ワークツリー（分離されたブランチとディレクトリ）を作成し、その中で Gemini CLI を起動します。既存の作業を破壊することなく、AI にコードを修正・実験させたいときに重宝します。

### 承認モードの使い分け
- **`gemini --approval-mode <mode>`**
  `-y` (YOLO) よりも細かい承認レベルの設定が可能です。
  - `default`: 毎回承認を求める
  - `auto_edit`: ファイル編集のみ自動承認し、コマンド実行などは確認する
  - `yolo`: すべて自動承認
  - `plan`: 読み取り専用モード

## 🔵 Priority: Low (高度な設定・補助機能)

特定の状況やトラブルシューティング、エッジケースで使用するコマンドです。

### モデルの切り替え
- **`gemini -m <model>`** / **`gemini --model <model>`**
  デフォルトと異なるモデルを明示的に指定して起動します。

### 拡張機能の管理 (Extensions)
Gemini CLI 自体の機能拡張を管理します。（スキルやMCPと似ていますが、CLI本体の振る舞いを変える拡張を指します）
- **`gemini extensions list`** / **`install`** / **`update`**

### 環境の分離とデバッグ
- **`gemini -s`** / **`gemini --sandbox`**
  サンドボックス環境内で実行します（影響範囲を狭めたい場合に使用）。
- **`gemini -d`** / **`gemini --debug`**
  デバッグモードでCLIを起動します（特定の環境ではF12でコンソールが開くなど、内部ログの確認に使用）。

### CI/CD・パイプライン向けの出力設定
- **`gemini -o <format>`** / **`gemini --output-format <format>`**
  CLIの出力を変更します。デフォルトの `text` 以外に `json` や `stream-json` が指定でき、別プログラムからのパース用途に利用します。

### アクセシビリティ
- **`gemini --screen-reader`**
  出力のフォーマットなどをスクリーンリーダーで読み上げやすい形式に変更します。
