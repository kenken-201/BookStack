# agy-CLI 使い方マニュアル

agy-CLI をより効率的・強力に活用するために抑えておくべきコマンドや操作方法、および連携するVimの基本操作を、優先度（High / Middle / Low）に分類して網羅的にまとめました。

---

## 🔴 Priority: High (日常的によく使う基本操作とフラグ)

日々の開発作業で最も頻繁に使用するコマンドや、生産性に直結するオプションです。

### 基本の起動コマンド
- **`agy`**
  通常の対話モード（インタラクティブモード）で起動します。プロンプトへの入力待ち状態になります。

- **`agy -p "プロンプト"`** / **`agy --prompt "プロンプト"`**
  非対話（ヘッドレス）モードで実行。指定したプロンプトの指示を一度だけ実行し、終了します。単発のタスクや、他のスクリプトからの呼び出しで活用します。

- **`agy -i "プロンプト"`** / **`agy --prompt-interactive "プロンプト"`**
  引数で渡したプロンプトを先に実行し、処理完了後そのまま対話モードに移行します。「とりあえずこのファイルを直して、詳細は後でやり取りする」といったケースで非常に便利です。

### セッション・履歴の管理
- **`agy --list-sessions`**
  現在のプロジェクトで保存されている過去のセッション一覧を表示します。

- **`agy -r <session_id>`** / **`agy --resume <session_id>`**
  過去のセッションを再開します。`<session_id>` には `--list-sessions` で表示されるインデックス番号を指定します。
  直近のセッションを再開したい場合は **`agy -r latest`** が便利です。

### 承認プロセスの自動化 (YOLOモード)
- **`agy -y`** / **`agy --yolo`**
  すべてのツール実行やファイル編集の確認（Yes/No）を自動で承認するモードです。一連の作業が長くなる際、エンターキーを何度も押す手間を省けます。

## 🟢 Priority: Vim (agy-CLI を使いこなすための最低限のVim操作)

agy-CLI が自動でプロンプト入力用やコミットメッセージ作成用にVimエディタを立ち上げた場合、またはVimの中からagy-CLIを呼び出す場合の必須操作マニュアルです。

### 1. agyからVimが立ち上がったときの操作（超基本）
プロンプトの複数行入力や、Gitコミットメッセージ等の編集でVimが起動した際は、以下の手順で操作します。

| アクション | キー操作 | 説明 |
| :--- | :--- | :--- |
| **編集を開始する** | `i` (挿入モード) | 画面左下に `-- INSERT --` と表示され、文字入力が可能になります。 |
| **編集を終了する** | `Esc` (ノーマルモード) | 入力状態から抜け、コマンド受付状態に戻ります（必須のクッション操作）。 |
| **保存して実行する** | `:wq` + `Enter` または `ZZ` | ファイルを保存してVimを閉じ、agy-CLIに処理を渡します。 |
| **キャンセルして戻る** | `:q!` + `Enter` または `ZQ` | 何も保存せずにVimを閉じ、agyの入力をキャンセルします。 |

> 💡 **ポイント**:
> Vimで動かなくなったと思ったら、とにかく `Esc` キーを数回叩き、ノーマルモードに戻ってから `:wq` (保存終了) か `:q!` (強制終了) を入力すれば安全に抜けられます。

### 2. Vimの中から agy-CLI を呼び出す・連携する
Vimでコードを書きながら、agyを外部ツールとして呼び出して処理させる強力な手法です。

- **`:!agy -p "プロンプト"`**
  Vimのノーマルモードから外部コマンドとして実行し、出力を一時画面で確認します。
- **`:r !agy -p "プロンプト"`**
  実行結果（標準出力）を、Vimで編集中の現在のカーソル位置に直接挿入します。AIが生成したコードやテキストをそのままファイルに取り込みたいときに非常に強力です。
- **`:%!agy -p "以下のコードをリファクタリングして"`**
  編集中のファイル全体（`%`）を標準入力として渡し、agyの出力結果でファイル全体を丸ごと上書き置換します。
- **`:'<,'>!agy -p "選択行をリファクタリングして"`**
  ビジュアルモードで一部の行範囲を選択した状態で `!` を押して実行すると、**選択範囲だけ**をagyの出力結果で置き換えます。
- **`:term agy`**
  Vimのターミナル機能を利用して、画面分割しつつ片方で対話モードを開きます。AIが提示したコードを隣のバッファへヤンク（コピー）＆ペーストする作業が格段にスムーズになります。

## 🟡 Priority: Middle (機能拡張・開発効率化ツール)

開発環境に合わせたカスタマイズや、外部知識・ツールの統合を行うためのコマンド群です。

### スキルの管理 (Skills)
エージェントに対して特定のライブラリやフレームワークの知識（ドキュメント等）を読み込ませる機能です。
- **`agy skills list`** : 利用可能なスキルの一覧を表示します。
- **`agy skills install <url>`** : Gitリポジトリなどから新しいスキルを追加します。
- **`agy skills enable <name>`** / **`disable <name>`** : プロジェクトごとに必要なスキルの有効化・無効化を切り替えます。

### MCP (Model Context Protocol) サーバーの管理
agy-CLI が外部のツールやAPI、ローカルのシステムと連携できるようにするための拡張機能です。
- **`agy mcp list`** : 設定済みのMCPサーバー一覧を表示。
- **`agy mcp add <name> <command>`** : 新規のMCPサーバーを登録します。
- **`agy mcp enable <name>`** / **`disable <name>`** : サーバーを有効化・無効化します。

### 安全なワークスペースの作成
- **`agy -w`** / **`agy --worktree`**
  新しい Git ワークツリー（分離されたブランチとディレクトリ）を作成し、その中で agy-CLI を起動します。既存の作業コピーを汚すことなく、AI にコードを修正・実験させたいときに重宝します。

### 承認モードの使い分け
- **`agy --approval-mode <mode>`**
  `-y` (YOLO) よりも細かい承認レベルの設定が可能です。
  - `default`: 毎回承認を求める
  - `auto_edit`: ファイル編集のみ自動承認し、コマンド実行などは確認する
  - `yolo`: すべて自動承認
  - `plan`: 読み取り専用モード

## 🔵 Priority: Low (高度な設定・補助機能)

特定の状況やトラブルシューティング、エッジケースで使用するコマンドです。

### モデルの切り替え
- **`agy -m <model>`** / **`agy --model <model>`**
  デフォルトと異なるモデルを明示的に指定して起動します。

### 拡張機能の管理 (Extensions)
agy-CLI 自体の機能拡張を管理します。
- **`agy extensions list`** / **`install`** / **`update`**

### 環境の分離とデバッグ
- **`agy -s`** / **`agy --sandbox`**
  サンドボックス環境内で実行します（影響範囲を狭めたい場合に使用）。
- **`agy -d`** / **`agy --debug`**
  デバッグモードでCLIを起動します。

### CI/CD・パイプライン向けの出力設定
- **`agy -o <format>`** / **`agy --output-format <format>`**
  CLIの出力を変更します。デフォルトの `text` 以外に `json` や `stream-json` が指定でき、別プログラムからのパース用途に利用します。

### アクセシビリティ
- **`agy --screen-reader`**
  出力のフォーマットなどをスクリーンリーダーで読み上げやすい形式に変更します。
