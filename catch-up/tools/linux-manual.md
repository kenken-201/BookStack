# Linux コマンド 使い方マニュアル

Linuxで日常的に使うコマンドから、トラブルシューティングやサーバー運用で威力を発揮する高度なコマンドまで、優先度（High / Middle / Low）に分類して網羅的にまとめました。

---

## 🔴 Priority: High (毎日使う必須コマンド)

ターミナルを開いたら息をするように使う、最も基本的かつ重要なコマンド群です。

### ファイル・ディレクトリ操作
- **`ls`** : カレントディレクトリの内容を一覧表示
  - `ls -la` : 隠しファイルを含む全ファイルを詳細情報付きで表示（パーミッション、所有者、サイズ、更新日時など）
  - `ls -lh` : ファイルサイズを人間が読みやすい形式（KB, MB）で表示
- **`cd <ディレクトリ>`** : ディレクトリの移動
  - `cd ..` : 一つ上のディレクトリへ
  - `cd ~` または `cd` : ホームディレクトリへ
  - `cd -` : 直前にいたディレクトリへ戻る
- **`pwd`** : 現在の作業ディレクトリのフルパスを表示
- **`mkdir <ディレクトリ名>`** : ディレクトリを新規作成
  - `mkdir -p a/b/c` : 親ディレクトリごと一括で作成
- **`cp <コピー元> <コピー先>`** : ファイルのコピー
  - `cp -r <ディレクトリ> <コピー先>` : ディレクトリを再帰的にコピー
- **`mv <移動元> <移動先>`** : ファイルの移動、またはリネーム
- **`rm <ファイル>`** : ファイルの削除
  - `rm -r <ディレクトリ>` : ディレクトリを再帰的に削除
  - `rm -rf` : 確認なしで強制削除（**要注意！** 取り返しがつかない）
- **`touch <ファイル名>`** : 空ファイルの作成（既存ファイルの場合はタイムスタンプを更新）

### ファイルの中身を見る
- **`cat <ファイル>`** : ファイルの内容をすべて表示
- **`less <ファイル>`** : ページ送りしながら閲覧（`q` で終了、`/` で検索）
- **`head -n <行数> <ファイル>`** : ファイルの先頭から指定行数だけ表示
- **`tail -n <行数> <ファイル>`** : ファイルの末尾から指定行数だけ表示
  - `tail -f <ファイル>` : リアルタイムでファイルの末尾を監視する（ログの追跡に必須）

### 検索
- **`grep <パターン> <ファイル>`** : ファイル内のテキスト検索
  - `grep -r <パターン> <ディレクトリ>` : ディレクトリ以下を再帰的に検索
  - `grep -i` : 大文字小文字を区別しない検索
  - `grep -n` : マッチした行番号を表示
- **`find <パス> -name "<ファイル名>"`** : ファイル名でファイルを検索
  - `find . -type f -name "*.log"` : カレントディレクトリ以下の `.log` ファイルを検索

### パイプとリダイレクト
Linuxの真の力を引き出す仕組みです。
- **`|` (パイプ)** : コマンドの出力を次のコマンドの入力に渡す
  - 例: `cat access.log | grep "ERROR" | wc -l` （ログからERROR行を抽出し、行数をカウント）
- **`>` (リダイレクト)** : コマンドの出力をファイルに書き込む（上書き）
- **`>>`** : コマンドの出力をファイルに追記
- **`2>&1`** : 標準エラー出力を標準出力にまとめる
  - 例: `command > output.log 2>&1`

### パーミッションと権限
- **`chmod <権限> <ファイル>`** : ファイルの権限を変更
  - `chmod 755 script.sh` : 所有者に全権限、グループ・その他に読み取り＋実行権限
  - `chmod +x script.sh` : 実行権限を付与
- **`chown <ユーザー>:<グループ> <ファイル>`** : ファイルの所有者を変更
- **`sudo <コマンド>`** : 管理者（root）権限でコマンドを実行

### プロセス管理 (基本)
- **`ps aux`** : 現在実行中の全プロセスを一覧表示
- **`kill <PID>`** : プロセスを終了させる
  - `kill -9 <PID>` : 強制終了（SIGKILL）
- **`Ctrl + C`** : 実行中のフォアグラウンドプロセスを中断
- **`Ctrl + Z`** : フォアグラウンドプロセスを一時停止（`bg` でバックグラウンド実行、`fg` でフォアグラウンドに復帰）

## 🟡 Priority: Middle (開発・運用効率を高めるコマンド)

日常的な開発やサーバー運用で使いこなすと差がつくコマンド群です。

### テキスト処理
- **`wc`** : 行数、単語数、バイト数をカウント
  - `wc -l <ファイル>` : 行数のみカウント
- **`sort`** : 行をソート
  - `sort -n` : 数値としてソート
  - `sort -r` : 逆順ソート
  - `sort -u` : 重複を除去してソート
- **`uniq`** : 連続する重複行を除去（`sort` と組み合わせて使うのが定石）
  - `sort file.txt | uniq -c` : 重複回数を表示
- **`awk`** : 列ベースのテキスト処理
  - `awk '{print $1, $3}' file.txt` : 各行の第1列と第3列を出力
  - `awk -F: '{print $1}' /etc/passwd` : 区切り文字を `:` に変更して第1列を出力
- **`sed`** : ストリームエディタ（テキストの置換・変換）
  - `sed 's/old/new/g' file.txt` : `old` を `new` に全置換
  - `sed -i 's/old/new/g' file.txt` : ファイルを直接書き換え（インプレース編集）
- **`cut`** : 列の切り出し
  - `cut -d',' -f1,3 data.csv` : CSV の1列目と3列目を抽出
- **`xargs`** : 標準入力をコマンドの引数に変換して実行
  - `find . -name "*.tmp" | xargs rm` : 見つかったファイルをまとめて削除

### アーカイブと圧縮
- **`tar`** : アーカイブの作成・展開
  - `tar czf archive.tar.gz <ディレクトリ>` : gzip圧縮でアーカイブ作成
  - `tar xzf archive.tar.gz` : gzip圧縮のアーカイブを展開
  - `tar xjf archive.tar.bz2` : bzip2圧縮のアーカイブを展開
- **`zip` / `unzip`** : ZIPファイルの作成・展開

### ネットワーク
- **`curl <URL>`** : URLに対してHTTPリクエストを送信
  - `curl -o <ファイル名> <URL>` : レスポンスをファイルに保存
  - `curl -X POST -H "Content-Type: application/json" -d '{"key":"value"}' <URL>` : POSTリクエスト
- **`wget <URL>`** : ファイルをダウンロード
- **`ping <ホスト>`** : ホストへの接続確認（ICMP）
- **`ssh <ユーザー>@<ホスト>`** : リモートホストにSSH接続
- **`scp <ローカルパス> <ユーザー>@<ホスト>:<リモートパス>`** : SSH経由でファイルを転送

### ディスク・ストレージ
- **`df -h`** : ファイルシステムのディスク使用量を表示
- **`du -sh <ディレクトリ>`** : ディレクトリの合計サイズを表示
  - `du -sh * | sort -rh | head` : カレントディレクトリ内のサイズが大きい順に表示

### システム情報
- **`top`** / **`htop`** : リアルタイムのプロセスモニタリング（htopは視覚的に見やすい）
- **`free -h`** : メモリの使用状況を表示
- **`uname -a`** : カーネル情報の表示
- **`uptime`** : システムの稼働時間とロードアベレージ

### 履歴とエイリアス
- **`history`** : コマンドの実行履歴を表示
  - `!<番号>` : 履歴番号を指定してコマンドを再実行
  - `!!` : 直前のコマンドを再実行（`sudo !!` は非常によく使う）
  - `Ctrl + r` : コマンド履歴のインクリメンタル検索（超便利）
- **`alias ll='ls -la'`** : コマンドのエイリアス（短縮名）を設定

### バックグラウンド実行
- **`<コマンド> &`** : コマンドをバックグラウンドで実行
- **`nohup <コマンド> &`** : ターミナルを閉じても動き続けるようにバックグラウンド実行
- **`jobs`** : バックグラウンドジョブの一覧を表示

## 🔵 Priority: Low (サーバー運用・トラブルシューティング向け高度な機能)

インフラ作業やトラブル発生時に頼りになる、プロフェッショナル向けのコマンドです。

### プロセスの詳細調査
- **`lsof -i :<ポート番号>`** : 指定ポートを使用しているプロセスを特定
- **`strace -p <PID>`** : プロセスが発行するシステムコールをトレース（デバッグに強力）
- **`pgrep -f <プロセス名>`** : プロセス名で検索してPIDを取得
- **`pkill -f <プロセス名>`** : プロセス名で検索して一括終了

### ネットワーク診断
- **`ss -tlnp`** : 待ち受けポートとプロセスの一覧を表示（`netstat` の後継）
- **`traceroute <ホスト>`** : ホストまでのネットワーク経路を追跡
- **`dig <ドメイン>`** : DNSレコードの問い合わせ
- **`nslookup <ドメイン>`** : DNSの正引き・逆引き確認
- **`ip addr`** : ネットワークインターフェースのIPアドレスを表示（`ifconfig` の後継）

### ユーザーとグループ管理
- **`whoami`** : 現在のユーザー名を表示
- **`id`** : 現在のユーザーのUID, GID, 所属グループを表示
- **`useradd` / `userdel`** : ユーザーの追加・削除
- **`passwd <ユーザー名>`** : パスワードの変更

### systemd によるサービス管理
- **`systemctl status <サービス名>`** : サービスの状態を確認
- **`systemctl start` / `stop` / `restart <サービス名>`** : サービスの起動・停止・再起動
- **`systemctl enable` / `disable <サービス名>`** : OS起動時の自動起動を有効化・無効化
- **`journalctl -u <サービス名> -f`** : サービスのログをリアルタイムで監視

### ジョブスケジューリング
- **`crontab -e`** : 定期実行ジョブ（cron）の編集
- **`crontab -l`** : 現在登録されているcronジョブの一覧を表示
  - 書式: `分 時 日 月 曜日 コマンド`
  - 例: `0 3 * * * /path/to/backup.sh` （毎日3時にバックアップ実行）

### その他の便利コマンド
- **`diff <ファイルA> <ファイルB>`** : 2つのファイルの差分を表示
- **`ln -s <ターゲット> <リンク名>`** : シンボリックリンクの作成
- **`env`** : 環境変数の一覧を表示
- **`export <変数名>=<値>`** : 環境変数の設定
- **`tee`** : 標準出力に表示しつつ、ファイルにも書き出す
  - 例: `command | tee output.log`（画面に出しながらログにも保存）
- **`watch -n <秒数> <コマンド>`** : 指定した間隔でコマンドを繰り返し実行し、結果を表示
  - 例: `watch -n 5 df -h`（5秒ごとにディスク使用量を監視）
