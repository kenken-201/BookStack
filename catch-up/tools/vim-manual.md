# Vim 使い方マニュアル

Vimの操作は非常に多岐にわたりますが、使用頻度や重要度に応じて「これだけは知っておくべき（High）」から「知っていると作業効率が劇的に上がる（Middle）」、「プロフェッショナル向け（Low）」に分類して網羅しました。

---

## 🔴 Priority: High (絶対必須！これがないと始まらない基本操作)

Vimを使う上で、息をするように使えるようになるべき最も基本的なコマンド群です。

### モードの切り替え
Vimの最大の特徴である「モード」を切り替える操作です。
- **`i`** : カーソル位置からインサートモード（挿入）に入る
- **`a`** : カーソルの次の文字からインサートモードに入る
- **`o`** : 現在の行の下に新しい空行を作り、インサートモードに入る
- **`O`** : 現在の行の行の上に新しい空行を作り、インサートモードに入る
- **`Esc`** または **`Ctrl + [`** : インサートモード等からノーマルモードに戻る

### カーソル移動 (基本)
矢印キーは使わず、ホームポジションを崩さずに移動します。
- **`h`** / **`j`** / **`k`** / **`l`** : 左 / 下 / 上 / 右 へ移動
- **`0`** : 行の先頭に移動
- **`^`** : 行の最初の文字（空白以外）に移動
- **`$`** : 行の末尾に移動
- **`gg`** : ファイルの先頭（1行目）に移動
- **`G`** : ファイルの末尾（最終行）に移動
- **`w`** : 次の単語の先頭に移動
- **`b`** : 前の単語の先頭に移動

### 編集・削除・コピペ (ノーマルモード)
- **`x`** : カーソル下の1文字を削除
- **`dd`** : 現在の行を削除（切り取りにもなる）
- **`yy`** : 現在の行をヤンク（コピー）
- **`p`** : ヤンクまたは削除した内容をカーソルの下（または右）にペースト
- **`u`** : 直前の操作を取り消す (Undo)
- **`Ctrl + r`** : 取り消した操作をやり直す (Redo)

### 保存と終了 (コマンドラインモード)
- **`:w`** : ファイルを上書き保存
- **`:q`** : Vimを終了
- **`:wq`** : 保存して終了
- **`:q!`** : 保存せずに強制終了

---

## 🟡 Priority: Middle (作業効率を飛躍的に高める操作)

基本的な操作に慣れてきたら、必ず身につけたい効率化のコマンド群です。

### 効率的なカーソル移動
- **`Ctrl + d`** / **`Ctrl + u`** : 画面を半分下 / 上にスクロール (Down / Up)
- **`Ctrl + f`** / **`Ctrl + b`** : 画面を1ページ下 / 上にスクロール (Forward / Backward)
- **`e`** : 単語の末尾に移動
- **`%`** : 対応する括弧（ `()` や `{}` など）にジャンプ
- **`<行番号>G`** : 指定した行番号にジャンプ (例: `50G` で50行目)

### 高度な編集とインサートモード移行
一発で「削除して即入力」状態になれる強力なコマンド集です。
- **`A`** : 行の末尾に移動してインサートモードに入る（`$` + `a` と同義）
- **`I`** : 行の先頭に移動してインサートモードに入る（`^` + `i` と同義）
- **`C`** : カーソル位置から行末までを削除してインサートモードに入る
- **`D`** : カーソル位置から行末までを削除する（インサートモードには入らない）
- **`cw`** : カーソル位置から単語末までを削除してインサートモードに入る
- **`.` (ドット)** : **【超重要】** 直前の操作（編集や変更等）を繰り返す
- **`>>`** / **`<<`** : 現在の行のインデントを深くする / 浅くする

### 検索と置換
- **`/キーワード`** : 下方向へキーワード検索（エンターで確定）
  - **`n`** : 次の検索候補へ移動
  - **`N`** : 前の検索候補へ移動
- **`?キーワード`** : 上方向へキーワード検索
- **`*`** : カーソル下にある単語と完全一致する単語を下へ検索（`#`で上へ検索）
- **`:%s/置換前/置換後/g`** : ファイル全体 (`%`) で、条件に合う文字列をすべて置換
- **`:%s/置換前/置換後/gc`** : １つずつ確認 (`c`) しながら置換

### ビジュアルモード (選択)
- **`v`** : 文字単位での選択モード
- **`V`** : 行単位での選択モード
- **`Ctrl + v`** : 矩形（ブロック）選択モード。複数行にまたがって同じ文字を挿入したい時などに重宝します

## 🔵 Priority: Low (マニア・プロフェッショナル向け高度な機能)

普段はあまり使わないかもしれませんが、特定の場面で絶大な威力を発揮する、知っていると一目置かれる機能です。

### テキストオブジェクト (Text Objects)
「単語の中身」や「括弧の中身」など、意味的なまとまりに対する操作です。
- **`ciw`** (Change Inner Word) : カーソルが単語のどこにあっても、その単語全体を削除してインサートモード
- **`yiw`** : カーソル下の単語全体をヤンク
- **`di"`** / **`ci"`** : ダブルクォーテーション `""` の中身だけを削除 / 変更
- **`vi(`** / **`vi{`** : 括弧 `()` や `{}` の中身を選択

### マクロ機能 (繰り返し作業の自動化)
複雑な手順を記録して再生できる強力な機能です。
- **`qa`** : 操作の記録を開始し、レジスタ `a` に保存する
- **`q`** : 操作の記録を終了する
- **`@a`** : レジスタ `a` に記録されたマクロを実行する
- **`@@`** : 直前に実行したマクロを再実行する

### レジスタ (複数のクリップボード)
Vimには複数のクリップボード（レジスタ）領域が用意されています。
- **`"ayy`** : レジスタ `a` に現在の行をヤンク
- **`"ap`** : レジスタ `a` の内容をペースト
- **`Ctrl + r` + `レジスタ名`** : インサートモード中に、指定したレジスタの内容を貼り付ける

### ウィンドウとタブの分割機能
- **`:sp`** (split) : ウィンドウを水平に分割
- **`:vs`** (vsplit) : ウィンドウを垂直に分割
- **`Ctrl + w` + `h/j/k/l`** : 分割したウィンドウ間のフォーカス移動
- **`:tabnew <ファイル名>`** : 新しいタブでファイルを開く
- **`gt`** / **`gT`** : 次のタブ / 前のタブへ移動

### その他の小技
- **`ZZ`** : `:wq` と同じ（保存して終了）。キー入力が速い。
- **`ZQ`** : `:q!` と同じ（保存せずに終了）。
- **`~`** (チルダ) : カーソル下の文字の大文字・小文字を反転させる。
- **`J`** (大文字) : 下の行を現在の行の末尾に結合する。
