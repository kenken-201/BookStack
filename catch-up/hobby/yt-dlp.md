# 🎥 yt-dlp 導入・操作完全マニュアル (M1 Mac対応)

`yt-dlp` は、YouTubeをはじめとする多数の動画共有サイトから動画や音声を高品質かつ高速にダウンロードできる強力なコマンドラインツールです。
安全性の低いブラウザ拡張機能（スパイウェアのリスクがあるものなど）の代わりに、安全で信頼性の高いこのCLIツールを使いこなしましょう。

---

## 🚀 1. M1 Mac への導入手順（インストール）

M1 Mac（Apple Silicon）では、パッケージマネージャーである **Homebrew** を使用して、ネイティブ（ARM64）版を簡単に導入できます。

### Step 1: ffmpeg のインストール
動画と音声を最高画質で結合（マージ）するために、裏で動作するマルチメディアエンコーダー `ffmpeg` が必須です。

```bash
brew install ffmpeg
```

### Step 2: yt-dlp のインストール
次に、`yt-dlp` 本体をインストールします。

```bash
brew install yt-dlp
```

### Step 3: 動作確認
インストールが正常に完了したか、バージョンを表示して確認します。

```bash
yt-dlp --version
```
バージョン番号（例: `2026.04.09` など）が表示されれば準備完了です！

---

## 📖 2. 基本操作（これだけ知っていればOK）

ターミナルを開き、以下のコマンドを実行します。

### ① 最もシンプルなダウンロード（最高画質・音質）
指定したURLの動画を、自動的に最高画質・最高音質（`ffmpeg`で自動結合）でカレントディレクトリにダウンロードします。

```bash
yt-dlp "動画のURL"
```
> 💡 **Tip:** URLは意図しないシェルの挙動を防ぐため、常にダブルクォーテーション `"` で囲むのが安全です。

### ② ダウンロード可能な画質・フォーマットの一覧表示
ダウンロードはせず、その動画で提供されている画質やファイル形式（フォーマット）のリストを確認します。

```bash
yt-dlp -F "動画のURL"
```
実行すると、左端に **ID（数字や文字列）** が書かれたリストが表示されます。

### ③ 特定の画質を指定してダウンロード
上記で確認したフォーマットIDを指定してダウンロードします。

```bash
# 例: 動画ID「137」（1080p MP4）と音声ID「140」（M4A）を結合してダウンロードする場合
yt-dlp -f 137+140 "動画のURL"
```

```bash
# 実際に試したやつ
# デスクトップに「動画タイトル.拡張子」で保存する場合
yt-dlp -f 135+140 -o "/Users/sasaki/Downloads/%(title)s.%(ext)s" "https://www.youtube.com/watch?v=vju0ljpNwKA"
```

## 🛠️ 3. 超便利！おすすめ実践コマンド集

普段の利用で非常によく使う、実用的なコマンドテンプレートです。

### 🎵 音声のみを抽出して保存（音楽・Podcast用）
動画から音声だけを抜き出し、高音質なオーディオファイルとして保存します。

* **MP3形式で保存する場合:**
  ```bash
  yt-dlp -x --audio-format mp3 "動画のURL"
  ```
* **M4A形式（Apple端末と親和性が高く、変換ロスがないためおすすめ）で保存する場合:**
  ```bash
  yt-dlp -x --audio-format m4a "動画のURL"
  ```

### 📁 保存先ディレクトリとファイル名のカスタマイズ
デフォルトではカレントディレクトリに保存されますが、`-o` オプションを使うことで、デスクトップや特定のフォルダに、分かりやすいファイル名で保存できます。

* **デスクトップに「動画タイトル.拡張子」で保存する場合:**
  ```bash
  yt-dlp -o "~/Desktop/%(title)s.%(ext)s" "動画のURL"
  ```
* **ダウンロード日やチャンネル名を含める場合:**
  ```bash
  yt-dlp -o "~/Downloads/[%(channel)s] %(title)s (%(upload_date)s).%(ext)s" "動画のURL"
  ```

### 📋 プレイリストやチャンネル全体のダウンロード
YouTubeのプレイリストやチャンネルのURLを指定すると、登録されているすべての動画を連続でダウンロードしてくれます。

```bash
# プレイリスト全体のダウンロード
yt-dlp "プレイリストのURL"

# プレイリストの1番目から5番目までを指定してダウンロード
yt-dlp --playlist-start 1 --playlist-end 5 "プレイリストのURL"
```

### 💬 字幕（日本語）も一緒にダウンロードする
動画に設定されている日本語の字幕を取得します。

* **字幕ファイルを別個で保存する場合 (.vtt形式など):**
  ```bash
  yt-dlp --write-subs --sub-langs "ja" "動画のURL"
  ```
* **動画自体に字幕を直接埋め込む場合 (MP4/MKV対応):**
  ```bash
  yt-dlp --embed-subs --sub-langs "ja" "動画のURL"
  ```

## 🔒 4. 認証が必要な動画のダウンロード（メンバーシップや年齢制限）

ログインが必要な動画や、年齢制限がかかっている動画はそのままではエラーになります。普段使っているブラウザのCookie（クッキー）を一時的に共有することで、安全にダウンロードが可能です。

```bash
# Chromeのログイン状態を利用する場合
yt-dlp --cookies-from-browser chrome "動画のURL"

# Braveを利用する場合
yt-dlp --cookies-from-browser brave "動画のURL"

# Vivaldiを利用する場合
yt-dlp --cookies-from-browser vivaldi "動画のURL"
```
> ⚠️ **注意:** ブラウザが起動中の場合、Cookieデータベースがロックされてエラーになることがあります。その場合はブラウザを一度終了してから実行してください。

---

## 🔄 5. メンテナンスとアップデート

YouTubeなどの動画サイトは頻繁に仕様変更を行います。ある日突然ダウンロードできなくなったり、速度が極端に遅くなったりした場合は、`yt-dlp` を最新版にアップデートしてください。

```bash
# Homebrew経由でアップデートする場合（推奨）
brew update && brew upgrade yt-dlp
```
